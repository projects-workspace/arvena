# Methodology implementation scope

25 September 2026. This note records the project owner's authorization for the current implementation; it does not change the approval labels of the source documents.

The supplied implementation task authorizes the public adaptation of the **Research, Selection and Collaboration Framework v1.0 Draft** and **Research Directions and Knowledge Map v0.1 Proposal**, both dated 24 September 2026. Stage 1/2 establish identity and platform context. The repository's `PROJECT_STATE.md` supplied the technical checkpoint at `73959c3`; source and branch were checked again before changes. The source documents were not edited, renamed or included in deployment assets.

Root domain identifiers, offer types, applied migrations, RLS/Auth settings, private dossiers and the protected Clean Water request handler/payload remain unchanged. `ARVENA_PLATFORM_ENABLED: true`, `ARVENA_EMAIL_DELIVERY_ENABLED: false`, `requestsEnabled: false` remain unchanged.

Deferred: detailed research and comparisons; actual offers/providers; ongoing research-task statuses; general public intake; an expanded knowledge CMS; medical reviews; trials; laboratory or certification operations; funding and staffed programmes. New forms, remote writes, schema changes, permission expansion, SMTP/domain spending, sourcing/B3 and production deployment require separate scope. No research task is represented as currently underway without an actual assignment.

Publication here means inclusion in the working website source. Future research conclusions and commercial publication still require real human approval.
